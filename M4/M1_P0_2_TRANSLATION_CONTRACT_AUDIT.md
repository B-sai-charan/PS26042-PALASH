# M1 P0-2 Translation Contract Audit

## 1. Backend Contract
The M1 FastAPI backend defines the translation endpoint at `POST /translate` in `app/api/translate.py`.
- **Request Pydantic Schema (`app/schemas/translation.py`):**
  ```python
  class TranslationRequest(BaseModel):
      text: str
      source_language: str = "hin_Deva"
      target_language: str = "sat_Olck"
  ```
- **Service Implementation (`app/services/translation_service.py`):**
  - Validates `text`, `source_language` in `{"hin_Deva"}`, `target_language` in `{"sat_Olck"}`.
  - Invokes `IndicTrans2` model (`ai4bharat/indictrans2-indic-indic-1B`) on CUDA GPU.
- **Response Structure:**
  ```json

    "source_language": "hin_Deva",
    "target_language": "sat_Olck",
    "latency_ms": 268.96,

  ```

## 2. Android Contract
The PALASH Android application defines its translation network interface in `com.sih2026.palash.data.network.PalashApiService`:
```kotlin
@POST("translate")
suspend fun translate(
    @Body request: TranslateRequestDto
): Response<TranslateResponseDto>
```
- **Request DTO (`com.sih2026.palash.data.network.dto.TranslateRequestDto`):**
  ```kotlin
  data class TranslateRequestDto(
      @SerializedName("text") val text: String,
      @SerializedName("source_language") val sourceLanguage: String = "hin_Deva",
      @SerializedName("target_language") val targetLanguage: String = "sat_Olck"
  )
  ```
- **Response DTO (`com.sih2026.palash.data.network.dto.TranslateResponseDto`):**
  ```kotlin
  data class TranslateResponseDto(
      @SerializedName("translated_text") val translatedText: String,
      @SerializedName("source_language") val sourceLanguage: String,
      @SerializedName("target_language") val targetLanguage: String,
      @SerializedName("latency_ms") val latencyMs: Double,
      @SerializedName("status") val status: String
  )
  ```
